# ANI PIN MATSURI v4 — 일본풍 웹 아케이드 / 온라인 배포 패키지

> 이 버전은 **플레이어의 PC에 Python 설치가 필요 없는 웹사이트용 패키지**입니다. 운영자는 Render 등 Python 서버 호스팅과 관계형 DB를 연결해 공개 URL을 발급받아야 합니다. ZIP을 다운로드하는 것만으로 인터넷에 자동 게시되지는 않습니다.

## v4 변경 사항

- 신사와 벚꽃, 야간 축제에서 영감을 받은 새로운 일본풍 반응형 다크 테마 (원작 애니메이션 이미지 미사용)
- **공식 데일리 리그**: 누구나 날짜별 같은 5문제, 1계정 1일 1회, 서버 채점, 주간 합산 순위
- **12초 러시**: 짧은 제한 시간의 별도 게임 (공식 순위에는 반영되지 않음)
- **무한 수련**: 자유롭게 반복하는 연습 게임 (공식 순위에는 반영되지 않음)
- **친구 1:1 결투**: 2인 초대 코드, 서버 채점, 친구별 결과
- **7초 순간 퀴즈**: 8문제, 도시/작품 4지선다, 연속 정답 콤보, 로그인 없이 플레이 가능. **공식 랭킹이 아닌 브라우저 내 개인 기록**
- **수집 도감**: 서버에서 기록을 계산하여 6가지 업적 잠금 해제
- **주간 TOP 5**: 실제 데일리 기록 순위 공개. 현금 상금 **미운영**.
- 잠재 유료 구독 플랜은 화면상 기획안만 표시. 결제 기능/자동 청구 **없음**.
- 광고 위치는 플레이와 분리. 실제 AdSense 게재는 승인·설정 후 별도 활성화.

## 공개 웹 배포 (이용자는 설치 없음)

**우선 `처음_인터넷에_공개하는_방법.md`를 읽으세요.** 기본 배포 지역은 한국 이용자를 고려해 `singapore`로 설정되어 있습니다. 현재 실제 URL은 발급되지 않았습니다.


1. 압축을 푼 폴더 **안의 파일과 디렉터리**를 GitHub 새 저장소 최상위에 업로드 (`server.py`, `requirements.txt`, `render.yaml`, `static/`, `places.json` 포함).
2. [Render Blueprints](https://dashboard.render.com/blueprints)에서 GitHub 저장소를 연결하고 `render.yaml` 배포를 승인.
3. 웹 서비스와 Postgres DB가 생성된 뒤 서비스가 `Live` 상태가 되면 Render에서 발급한 `https://...onrender.com` URL을 이용자에게 공유.
4. **서로 다른 두 기기**에서 계정 등록 → 데일리 완료 → 랭킹 확인 → 친구 결투 완료로 실제 클라우드 동작을 검증.
5. 운영 전에는 반드시 이용약관/개인정보 안내/사업자 정보, 콘텐츠 라이선스, 게임물 등급분류, 보안, DB 백업, 이용자 신고/관리 정책을 정비.

> 무료 Render Postgres는 **30일 후 만료**되므로 테스트 데이터만 사용하세요. 무료 서버는 유휴 후 절전 및 재시작 시 로컬 파일 소실 위험이 있습니다. 실제 고객·장기 운영은 유료 DB 및 정기 백업 구성을 권장합니다. https://render.com/docs/free
>
> 현재 이 패키지의 인터넷 호스팅은 연결되지 않았으므로 실행할 **공개 URL은 아직 없습니다**.

## 로컬 개발자 테스트 (사이트 이용자에게 불필요)

```bash
python -m pip install -r requirements-test.txt
python -m pytest -q
uvicorn server:app --host 127.0.0.1 --port 8010
```

브라우저에서 `http://127.0.0.1:8010` 접속. 실제 API 점수 계산은 서버의 시작 시각 기준이며, 클라이언트가 입력한 점수 자체는 받지 않습니다.

## 실제 운영에 남은 중요한 작업

- 16개 초기 애니 성지 데이터의 위치/설명 검증 및 문제 수 확장. 원본 애니 장면/음원/캐릭터 이미지 사용은 권리 확보 후.
- 하나의 사용자에 대해 추가 계정 생성, 답안 공유, 시계 지연, 자동화 봇 등의 부정행위 방지 및 점수 감사 로그 강화. **현금 대회용 공정성을 보장하는 수준 아님**.
- Render 등 실제 퍼블릭 서비스 배포, 도메인·SSL, 월간 백업, 관리 도구, 웹 분석, 관리자 문의 채널.
- 광고: 승인 받은 계정만 환경변수 `ADSENSE_CLIENT_ID`, `ADSENSE_SLOT_ID` 입력. AdSense 정책을 준수하고 유효하지 않은 트래픽 발생을 막기. 광고 시청/클릭에 대한 현금 지급이나 강제 시청은 구현하지 않음.
- 구독: 실제 결제연동 없음. 가격표의 ₩3,900은 **가설 가격**이고 지급·계약을 요구하지 않음. 향후 프리미엄 상품은 꾸미기/아카이브 등 공정 경쟁에 영향을 주지 않는 기능 중심.
- 현금 상금: **현재 미운영**. 운영 전 게임물관리위원회 문의 및 게임산업법·세금·청소년 보호·상금 약관 법률검토 필요. 무료 순수 실력 대회도 개별 설계에 따라 판단이 달라질 수 있음.

## 기술 사양

FastAPI, SQLAlchemy, SQLite(로컬)/Postgres(클라우드), vanilla JavaScript, SVG 일본 지도. 12개 자동 API 테스트 및 데스크톱/모바일 브라우저 플로우 테스트 완료. 현재 일반 웹 유저 실사용/법률 적합성/구독 결제/광고 승인은 검증되지 않음.
